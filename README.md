# Human Factors for RPAS - CASARA Training

Interactive HTML presentation covering human factors training for Remote Pilot Aircraft Systems (RPAS) drone pilots.

## Content

25 slides covering:
- Visual scanning techniques
- Fatigue, medication, and alcohol effects
- Swiss Cheese Model accident analysis
- Automation complacency
- Real case study: TSB A21O0069 (Buttonville collision)

Based on TP15263 Section 3 and Transport Canada standards.
